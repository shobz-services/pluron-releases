# Pluron for macOS

Installers and updates for Apple Silicon Macs are published in [Releases](https://github.com/shobz-services/pluron-releases/releases).

Open the DMG, drag Pluron into Applications, eject the DMG, and open Pluron from Applications.

These early builds use development signing. macOS may require **Open Anyway** in Privacy & Security on first installation.

When **Updates available** appears in Pluron, click it to download, install, and relaunch.
